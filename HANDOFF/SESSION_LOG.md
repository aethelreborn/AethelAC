### Strictness techniques researched (for hard PvP-level setup)
- Prediction threshold 0.001 blocks; immediate-setback-threshold 0.1; max-advantage 1.
- Reach: threshold 0.0005 (+ 0.03 forced expansion on 1.9-1.18.1); enable-post-packet adds flush packet
  => noticeably more reach catches on 1.8 PvP.
- Timer: drift 120ms (high drift => 1.8 fast-use bypasses); TimerLimit ping-abuse-limit-threshold
  default 1000ms is lenient -> lower (1000 => 300-400).
- max-ping-out-of-flying 1000 -> lower (flying cheat window shrinks); max-ping-firework-boost 1000 -> lower.
- packet-spam-threshold 100 -> lower (kick faster on packet floods).
